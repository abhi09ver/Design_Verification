Instrument 2 · Sections 3.3.2 and 3.3.3

How the linker splits a PC-relative offset

auipc adds hi << 12 to the PC; addi then adds a sign-extended 12-bit lo. If lo would be 0x800 or more it reads as negative, so hi must round up: hi = (offset + 0x800) >> 12.

Presets:

auipc (R_RISCV_PCREL_HI20)
addi (R_RISCV_PCREL_LO12_I)
Check: PC + (hi << 12) + lo
Companion to the Ch 3 tab of your notes. The ISS models only the instructions sumtest uses, on RV64 with the C extension; instret starts at 5 because the simulator's boot ROM has already retired five instructions, which matches the book's Sail trace.
