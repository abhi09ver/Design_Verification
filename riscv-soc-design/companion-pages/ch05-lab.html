Experiment 1 · Sections 5.4 and 5.8

Statement coverage says 100%. Did the tests find the bug?

DUT: s = a ^ b ^ c, cout = a&b | a&c | b&c. Expression coverage counts each input of each equation as covered only when it was seen at 0 and 1 while it alone decided the output (for cout's input a, that means b ≠ c). This reproduces the book's 83.33% / 91.66% example.
