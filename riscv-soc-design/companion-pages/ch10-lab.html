Experiment 1 · Sections 10.1.3 and 10.4

Offset bits pick the byte, set bits pick the row, the rest is the tag

offset = log2(line bytes) · sets = capacity / (line bytes × ways) · set bits = log2(sets) · tag = address bits − set − offset. Tag storage = sets × ways × tag bits: overhead the "capacity" figure leaves out.

Experiment 2 · Sections 10.1.4–10.1.7

Watch hits, misses, evictions and writebacks, and name every miss

Write-back, write-allocate, 16-byte lines, 32-bit addresses. A miss is compulsory if the line was never touched before, capacity if a fully associative LRU cache of the same size would also miss, otherwise conflict. The victim is the first invalid way, else the tree-pLRU choice (or way 0 with the stuck-LRU bug).

Experiment 3 · Sections 10.1.7 and 10.4.4

Click a way to use it; the path flips to point away

N−1 bits per set. A bit of 0 means the victim is on the left, 1 means the right. Victim = follow the bits from the root. Update = every node on the path to the accessed way points away from it. LRU[N−2] is the root; the rest go top to bottom, left to right (book Fig. 10.20).

Experiment 4 · Section 10.1.1

AMAT = A1 + MR1 × (A2 + MR2 × A3)

The miss penalty of a level is the AMAT of the level above it. Defaults are book Example 10.3: L1 1 cycle, L2 3 cycles at 80% hit, DRAM 30 cycles, 40% loads/stores.
