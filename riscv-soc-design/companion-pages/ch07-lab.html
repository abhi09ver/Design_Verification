Experiment 1 · Section 7.2.2

Forward if you can, stall if you must, flush if you guessed wrong

Model rules. With forwarding: an ALU result is usable in the next instruction's Execute; a load result is usable two cycles after the load's Execute (a 1-cycle load-use stall when adjacent). Without forwarding: the consumer's Decode must overlap the producer's Writeback (the register file writes in the first half of the cycle, reads in the second). Branches predict not-taken; a taken branch redirects Fetch after it resolves.

Every shift is a right shift; every compare is a subtraction

32-bit funnel shifter (book Table 7.5): build a 63-bit Z, shift right, keep the low 32 bits. Left shifts use the complemented amount ~k. Flags from A − B = A + ~B + 1: sltu = NOT carry, slt = N XOR V.
