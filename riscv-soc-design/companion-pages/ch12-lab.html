Experiment 1 · Sections 12.2, 12.4 and 12.5.2

One SRAM port, read one cycle early: who pays when a store just wrote it?

Model: all accesses hit; 16-byte lines, 8 sets (set = address bits 6:4). At the end of every cycle the port either writes (a store in Memory) or reads one set: the next instruction's (from IEUAdrE) or, when SelAdr = 1, Memory's own. A load needs a valid read of its set when it reaches Memory. use = an ALU op that needs the previous load (load-use stall).

Experiment 2 · Table 12.2 and Figs. 12.14–12.24

Seven operations, one walker: which path lights up, and who owns the address

Ownership: IEUAdrM in a normal cycle · HPTW (SelHPTW) during a walk · the cache FSM's CacheBusAdr + BeatCount during a fill, writeback or flush. Every change of owner is a seam to verify.

Experiment 3 · Sections 12.2.1–12.2.3 and Table 12.1

A line is beats × bus width; a dirty miss is two bursts, back to back

Beats = line bits / bus bits · HSIZE = bus width · first beat waits w cycles, then one beat per cycle · fetch ≈ 1 + w + beats · writeback then fetch: twice that, minus 1 when the fetch address overlaps the last writeback data beat (Wally's CacheWriteback → CacheFetch).
