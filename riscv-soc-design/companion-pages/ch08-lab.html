Trap entry saves state in one step; mret puts it back

Model rules (M-mode traps only, no delegation). Entry: mepc ← PC of the instruction that did not complete: the one that faulted (exceptions) or the one about to run (interrupts). The pc box below is the instruction about to execute; mcause, mtval ← reason; MPIE ← MIE; MIE ← 0; MPP ← current mode; mode ← M; PC ← mtvec base, plus 4 × cause for interrupts in vectored mode. mret: PC ← mepc; MIE ← MPIE; MPIE ← 1; mode ← MPP; MPP ← U (the lowest supported mode).

Experiment 2 · Section 8.2

The address tells you who may touch a CSR

The 12-bit CSR address carries its own permissions. Bits [11:10] = 11 means read-only: any write traps as illegal. Bits [9:8] give the lowest privilege that may access it: 00 = U, 01 = S, 10 = H (hypervisor), 11 = M. Note that csrr is csrrs rd, csr, x0, which does not write, so it never trips the read-only check.

Experiment 3 · Section 8.2

Pending, enabled, globally enabled, then priority

An interrupt is taken when mip & mie has the bit set and its target mode is globally enabled. Target is S if the bit is set in mideleg, else M. A target is globally enabled when the hart runs at a lower mode (always), or at the same mode with that mode's IE bit set; never when the hart runs above it. Priority: MEI > MSI > MTI > SEI > SSI > STI.

Experiment 4 · mstatus MBE, SBE, UBE

Same word, two byte orders

RISC-V is little-endian by default: the least significant byte sits at the lowest address. mstatus.MBE/SBE/UBE can make data accesses big-endian per mode; instruction fetch is always little-endian.
