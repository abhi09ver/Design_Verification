The WRAP Burst, Step by Step

An INCR burst that lives inside a fixed, aligned window and loops back to the window's start when it reaches the end.
Window = (LEN+1) × 2^SIZE
Lower = INT(Start / Window) × Window
Upper = Lower + Window → jump to Lower

1Why WRAP exists: critical word first

  • A CPU misses in its cache on one word, e.g. 0x14, and has to fetch the whole cache line 0x00–0x1F.
  • With INCR it would have to start at 0x00 and wait for 0x14 to arrive 6th.
  • With WRAP it starts at 0x14 — the word the CPU is stalled on comes back first — then the burst wraps round to fill the rest of the line.
  • Result: lower miss latency with a single burst, and the line is still fetched completely.
One-line answer: WRAP fetches a whole aligned block but in an order that starts at the address you actually need.

3The algorithm — 4 steps you can do on a whiteboard

Step 1 · Window size
W = (LEN+1) × 2^SIZE
e.g. 8 beats × 4 B = 32 B
Step 2 · Lower boundary
L = INT(Start / W) × W
(= Start with low bits cleared)
Step 3 · Upper boundary
U = L + W
first address outside the window
Step 4 · Walk
add 2^SIZE each beat; when address = U, set it to L. Stop after LEN+1 beats.
Reference model (SystemVerilog)
function automatic void wrap_addrs(
    input  bit [31:0] start, input bit [7:0] len,
    input  bit [2:0]  size,  ref bit [31:0] q[$]);
  int unsigned nb    = 1 << size;
  int unsigned win   = nb * (len + 1);
  bit [31:0]   lower = (start / win) * win;
  bit [31:0]   upper = lower + win;
  bit [31:0]   a     = start;
  repeat (len + 1) begin
    q.push_back(a);
    a += nb;
    if (a == upper) a = lower;
  end
endfunction
Bit-trick version (window is a power of 2)
mask  = W - 1;               // e.g. 32 B → 0x1F
lower = start & ~mask;
next  = lower | ((addr + nb) & mask);
Only the low log2(W) bits move; upper bits stay fixed. That's exactly how RTL address generators implement WRAP — no comparator needed.
Shortcut: the number of beats before the wrap = (U − Start) / 2^SIZE. Beats after the wrap = the rest.
Special case: if Start = L, the burst never wraps and is identical to INCR.

?WRAP interview Q&A

QuestionCrisp answer
What is a WRAP burst?INCR that loops back to the start of an aligned window of size (LEN+1)×2^SIZE.
Main use?Cache line fill — critical word first.
Allowed lengths?2, 4, 8, 16 beats.
Why must the length be a power of 2?So the window is self-aligned and address bits wrap naturally.
Can WRAP cross 4 KB?No — window ≤ 2 KB and aligned to its size.
Can WRAP start unaligned?No — must be aligned to 2^SIZE.
WRAP 4 × 4 B from 0x2C?Window 0x20–0x2F → 0x2C, 0x20, 0x24, 0x28.
WRAP 8 × 2 B from 0x0A?Window 0x00–0x0F → 0x0A, 0x0C, 0x0E, 0x00, 0x02, 0x04, 0x06, 0x08.
When is WRAP identical to INCR?When the start address is the lower boundary.
How does RTL generate the next address?Increment only the low log2(window) bits; upper bits fixed.
Does WRAP change WSTRB rules?No — lanes follow each beat's address, as for INCR.
