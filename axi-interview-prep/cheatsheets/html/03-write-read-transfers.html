1Single-beat transfer (AWLEN = 0)

  • One AW handshake, one W beat with WLAST = 1, one B response.
  • AW and W can handshake in the same cycle, or W can even come first.
  • Fastest write = 2 cycles (AW+W together, then B). Fastest read = AR, then R next cycle.
  • AXI-Lite is always this case — no LEN, no LAST, no ID.
Write orderings the slave must handle
AWthenWthenB— normal
AW + W same cyclethenB— fastest
WthenAWthenB— legal, often missed in TBs

3Byte lanes: narrow & unaligned transfers (32-bit bus = 4 lanes)

Narrow INCR · SIZE = 1 B · start 0x00 · 4 beats
beat 1B3B2B1B00001
beat 2B3B2B1B00010
beat 3B3B2B1B00100
beat 4B3B2B1B01000
Narrow = SIZE smaller than bus. Active lane moves each beat with the address.
Unaligned INCR · SIZE = 4 B · start 0x01 · 3 beats
0x01B3B2B1B01110
0x04B3B2B1B01111
0x08B3B2B1B01111
Only the first beat is unaligned; later beats snap to aligned addresses (0x04, 0x08). Total = 11 bytes.
Rules to remember
  • Lane for a byte = addr mod (bus bytes) (little-endian).
  • INCR next address = aligned(addr) + 2^SIZE.
  • FIXED narrow: the same lanes every beat.
  • WRAP must start aligned — unaligned WRAP is illegal.
  • Reads use the same lane logic; master just picks the bytes it needs.
  • WSTRB must be 0 on lanes outside the transfer.

4What to check & cover for transfers

Checks (monitor / SVA)
  • Payload (WDATA, WSTRB, RDATA…) stable while VALID && !READY — the T4 / T6 stall cases above.
  • Exactly LEN+1 beats; LAST only on the final beat.
  • BVALID never before WLAST handshake; RVALID never before AR handshake.
  • WSTRB lanes match address/SIZE for narrow & unaligned beats.
  • Read data matches reference memory; write updates only strobed bytes.
Coverage
  • Back-pressure on every channel (READY low for 0, 1, N cycles).
  • W before AW, same-cycle AW+W, AW before W.
  • Back-to-back bursts (no idle), overlapped addresses, max outstanding.
  • Narrow × aligned/unaligned × burst type × LEN.
  • Error responses mid-burst on R (RRESP changes beat to beat).

?Transfer interview Q&A

QuestionCrisp answer
Minimum cycles for a single write?2 — AW+W handshake together, B next cycle.
What happens when WREADY drops mid-burst?Master holds the same WDATA/WSTRB and WVALID until WREADY returns.
Can RREADY be held HIGH all the time?Yes, and it's common; it just means "always ready".
How does the slave know the burst ended?WLAST (it may also count LEN+1).
Can a read error stop the burst early?No — all LEN+1 beats are still returned with RRESP error.
Start 0x03, SIZE 4 B, 2 beats — strobes?Beat 1: 1000, beat 2 (0x04): 1111.
Why overlap addresses?Hides latency; keeps the data channel busy back-to-back.
Can AW for burst 2 come before W of burst 1 ends?Yes — outstanding writes; in AXI4 W data still follows AW order.
Who drives BREADY / RREADY?The master.
