Reporting done right

  • One ID per check (UART_FE, UART_PE, UART_BRK, UART_OE, UART_BAUD) so logs can be filtered and severities overridden per ID.
  • Severity: DUT violation = uvm_error; TB-injected and seen = info; avoid warnings nobody reads.
  • Message content: time, direction (TX/RX), data, which bit, measured vs expected.
  • Suppress cascades: after FE or break, mark "resyncing" and hold follow-up checks until the line is idle.
  • report_phase summary: frames seen, per-error counts, expected vs unexpected.
  • Knobs: every check has an enable bit in cfg — but never disable one to make a test pass.

Expected errors — a report catcher

class fe_expect_catcher extends uvm_report_catcher;
  `uvm_object_utils(fe_expect_catcher)
  int seen;
  function new(string name = "fe_expect_catcher");
    super.new(name);
  endfunction
  function action_e catch();
    if (get_id() == "UART_FE" &&
        get_severity() == UVM_ERROR) begin
      set_severity(UVM_INFO);  seen++;
    end
    return THROW;
  endfunction
endclass
// test: uvm_report_cb::add(null, catcher);
// check_phase: seen == number injected

Rapid-fire revision — the whole series in 10 lines

1. Idle 1, start 0, 5–8 data LSB-first, optional parity, 1–2 stop of 1.
2. RX: 16× oversample, confirm start at mid-bit, sample every 16 ticks.
3. Tolerance: last sample at 9.5 T → ~4.6% total → design to ±2% per side.
4. Check baud by timing every edge gap as n × T, never by counting transitions.
5. Framing = stop bit sampled 0. Resync policy comes from the spec.
6. Parity catches odd-count flips only; compute over configured width.
7. Break = low longer than one char; one 0x00 + BI per break, then wait for mark.
8. Overrun is invisible on the wire — model FIFO with line + bus monitors.
9. Symmetric bugs pass loopback; verify one raw waveform against the spec.
10. Unique IDs, expected-error flags or catchers, cascade suppression, summary in report_phase.
